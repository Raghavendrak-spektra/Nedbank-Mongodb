## Question
After enabling MongoDB authorization and restarting `mongod`, you try to access the database without credentials and the operation is rejected. What does this result indicate?

## Options
Option 1 : MongoDB authorization is enforcing authentication, so unauthenticated access is no longer permitted.

Option 2 : The `customer360` database has been deleted and must be restored from backup.

Option 3 : The `c360Admin` account was created in the wrong database because anonymous users should still have read access.

Option 4 : The MongoDB service failed to start because all connection attempts should succeed without credentials.

## Answers
Option 1 : 1
