## Question

The reporting application only needs to query customer and order data. It must not insert, update, or delete documents. Which permission approach best follows the principle of least privilege?

## Options

Option 1 : Grant project owner access.

Option 2 : Grant readWriteAnyDatabase.

Option 3 : Grant only the required read access to the application database.

Option 4 : Grant unrestricted database administrator access.

## Answers

Option 3 : 1

## Correct Answer Feedback

Option 3 is correct, because the reporting application only requires read operations. Granting only the necessary read permission minimizes unnecessary access.

## Incorrect Answer Feedback

Selected Option is not correct. Option 3 is the correct answer because least privilege means granting only the permissions required for the application's intended function.
