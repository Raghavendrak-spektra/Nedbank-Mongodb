## Question

The application can now connect to the Atlas cluster after the network configuration was corrected. Which test is the most appropriate next step to confirm that the application can access the required data?

## Options

Option 1 : Disable authentication.

Option 2 : Successfully query documents from the required customer360 collection.

Option 3 : Grant the application administrator permissions.

Option 4 : Delete and recreate the database.

## Answers

Option 2

## Correct Answer Feedback

Option 2 is correct, because querying the required collection directly verifies that the application can access the data it is expected to use.

## Incorrect Answer Feedback

Selected Option is not correct. Option 2 is the correct answer because successful access to the required collection is the appropriate functional validation.
