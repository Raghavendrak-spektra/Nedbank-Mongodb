## Question

The reporting account should be able to read customer360 data but should not be able to create database users or perform administrative operations. Which result would best confirm the intended access model?

## Options

Option 1 : Only administrative operations succeed.

Option 2 : All operations are denied.

Option 3 : Reads succeed and administrative operations are denied.

Option 4 : Reads and administrative operations both succeed.

## Answers

Option 3

## Correct Answer Feedback

Option 3 is correct, because the account's intended purpose is reporting. Successful reads combined with denied administrative operations demonstrate that access is restricted appropriately.

## Incorrect Answer Feedback

Selected Option is not correct. Option 3 is the correct answer because a least-privilege reporting account should perform its required reads while being prevented from administrative actions.
