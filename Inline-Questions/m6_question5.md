## Question
You have completed all recovery steps and functional verification tests, confirming that mongod is active, enabled, and serving customer360 data successfully. Now you create an incident note documenting: symptom, diagnosis, checks used, recovery action, and verification results. Why is it important to save this structured incident evidence in `/opt/cloudlabs/mongodb-customer-data/evidence/m6-incident-note.txt` rather than simply announcing verbally that the issue is fixed?

## Options
Option 1 : Written documentation is only required for audit purposes and does not affect operational recovery.
Option 2 : Structured incident records serve multiple purposes: they preserve evidence for post-incident review, enable root cause analysis to prevent recurrence, provide a historical record for the organization, and allow the validation system to confirm that proper troubleshooting procedures were followed.
Option 3 : Documentation is a waste of time; as long as the service is running, there is no need for any record.
Option 4 : Incident notes are required by MongoDB licensing agreements but have no operational value.

## Answers
Option 2

## Correct Answer Feedback
Option 2 is correct. Professional incident response requires documentation. A structured incident note preserves: (1) the symptom so similar problems can be recognized, (2) the diagnosis process and evidence used, (3) the corrective action taken, and (4) the verification that recovery was successful. This record enables future similar issues to be diagnosed faster, supports post-incident root cause analysis, and demonstrates that proper procedures were followed. Documentation is not a burden; it is a best practice that reduces organizational risk.

## Incorrect Answer Feedback
The selected option is not correct. Option 2 is the correct answer. Incident documentation is a critical part of professional operations. Records enable learning from incidents, support faster resolution of similar future problems, and demonstrate due diligence in incident response procedures.
