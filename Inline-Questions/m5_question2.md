## Question
You have created `c360Admin` and now need MongoDB to require valid credentials for database access. Which configuration change is required in `/etc/mongod.conf`?

## Options
Option 1 : Add `net.authorization: enabled` and restart the virtual machine.

Option 2 : Add `storage.authentication: required` and reload the `customer360` collection.

Option 3 : Add `security.authorization: enabled` and restart the MongoDB service.

Option 4 : Add `system.users: protected` and restart only the MongoDB shell.

## Answers
Option 3 : 1

## Correct Answer Feedback
Option 3 is correct
